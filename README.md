# Airbnb NYC Listings Analysis using Python

## Project Overview

This project focuses on analyzing **Airbnb listings in New York City** using Python to understand pricing, listing distribution, availability, room types, and neighborhood-level patterns.

An end-to-end analytical workflow was developed using **Pandas and NumPy**, including data cleaning, validation, feature engineering, exploratory data analysis, KPI analysis, and visualization.

## Objectives

* Understand Airbnb listing and pricing patterns.
* Analyze pricing across NYC boroughs and neighborhoods.
* Study room type and listing distribution.
* Analyze listing availability.
* Create meaningful pricing segments.
* Generate business insights from the dataset.

## Data Preparation

The dataset was prepared for analysis by performing:

* Missing value checks and treatment.
* Duplicate record checks.
* Data validation.
* Invalid value identification.
* Data type standardization.
* Creation of analysis-ready datasets.

## Feature Engineering

Listings were grouped into pricing segments:

* Low
* Medium
* High
* Luxury

These segments were used to compare pricing patterns and understand the distribution of listings across different market levels.

## Key Analysis

The project analyzes:

* Average listing price.
* Pricing differences across boroughs.
* Room type distribution.
* Neighborhood-level pricing.
* Listing availability.
* Listing density.
* Pricing and availability relationships.
* High-demand and high-value areas.

## Visualizations

Charts and analytical reports were created to communicate:

* Pricing distribution.
* Borough-wise pricing.
* Room type distribution.
* Availability patterns.
* Pricing segment distribution.
* Neighborhood-level trends.
